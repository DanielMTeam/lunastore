**LunaStore** — це проєкт ентузіастів, створений для поціновувачів ретроестетики. Він дає змогу легко знаходити та завантажувати програми для старих операційних систем, передусім для Windows XP.

**LunaStore** побудований на доволі сучасному стеку, щоб гарантувати високу продуктивність, гарну оптимізацію та роботу навіть в Internet Explorer 6:

* **Мова та рушій:** Django (Python), власний рушій LunaSpire (написаний на Go; для CDN та інших крутих речей у майбутньому)
* **База даних:** PostgreSQL 18
* **Інфраструктура:** Docker, Docker Compose
* **Автентифікація:** є підтримка OpenID (OIDC)
