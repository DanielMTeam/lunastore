# <center>Документация LunaStore API</center>

API LunaStore является RESTful типа и может использоваться для взаимодействия с инстансом LunaStore. Для отправки запросов и ответов используется JSON (`Content-Type: application/json`).

Для описания самих API-методов и взаимодействия с ними используется Swagger UI, на который можно зайти используя домен `api.store.myslivets.com`. Относительно Docker, контейнер с LunaStore API располагается на 7088 порте. 

У LunaStore API, помимо всего этого, есть своя система нумерации ошибок, а работает она следующим образом: 

| Нумерация | Описание нумерации |
| ----- | ----- |
| 0xxx | Ошибка общего типа |
| 1xxx | Ошибка модели User |
| 2xxx | Ошибка модели Application |
| 3xxx | Ошибка модели Category |

А вот весь список ошибок, которые Вы можете получить, используя LunaStore API:
| Номер | Кодовое значение ошибки | Описание |
| ---- | ------ | ---------- |
| 0 | EVERYTHING_IS_ALRIGHT | Все отлично (швепс чуитс) |
| 1 | UNKNOWN_ERROR | Неизвестная ошибка. Обычно, обознает ошибку со стороны Backend'а инстанса (http error 500) |
| 2 | VALIDATION_ERROR | Ошибка валидации. Может возникнуть, если вы не указали значение необходимого поля, при отправке запроса на API |
| 3 | NOT_FOUND | То же самое, что и HTTP ошибка 404 |
| 1000 | USER_NOT_FOUND | Данного пользователя не существует |
| 1001 | USER_IS_BLOCKED | Данный пользователь заблокирован |
| 2000 | APPLICATION_NOT_FOUND | Данное приложение не существует |
| 2001 | APPLICATION_IS_UNDER_DMCA | Данное приложение находится под блокировкой из-за DMCA страйка |
| 3000 | CATEGORY_NOT_FOUND | Данная категория не найдена |

А теперь, давайте отправим свой первый запрос на LunaStore API (пусть это будет эндпоинт `/service/heartbeat`):

```bash
curl -X 'GET' \
  'http://api.store.myslivets.com/method/service/heartbeat/' \
  -H 'accept: application/json'
```

..и мы получим подобный ответ: 
```json
{
  "status": "ok",
  "timestamp": "2026-02-03T07:33:25.768663",
  "version": "1.1.0"
}
```

Остальное описание работы с API методами есть на SwaggerUI: `api.store.myslivets.com`
