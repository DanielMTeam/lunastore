# План улучшения админки LunaStore

Основа: существующий Django Admin с Unfold. Бизнес-правила модерации и права доступа сохраняются.

## 1. Навигация и визуальные дефекты

- Один активный пункт меню, включая карточки, историю и страницы удаления.
- Разделы по задачам: рабочий стол, модерация, каталог, пользователи, безопасность, настройки.
- Поиск меню; вкладки только для связанных представлений.
- Статусы и оценка риска с читаемыми цветами в обеих темах.
- Клавиатурный фокус, перенос длинных значений, адаптивные формы, уменьшение анимаций.

## 2. Языки

- Переключатель ru/en/uk/be/kk через Django set_language без изменения адресов админки.
- Перевод меню, рабочего стола, интерфейса отзывов и новых компонентов.
- Язык интерфейса независим от вкладок переводов контента.
- Постепенно переводить оставшиеся старые формы и сообщения, проверяя полноту через Tolgee.

## 3. Рабочий стол

- Доступные сотруднику очереди с количеством ожидающих заявок и ссылками на фильтр.
- Самые старые заявки каждой очереди; пустое состояние.
- Все виды модерации: приложения, дистрибуции, разработчики, отзывы, жалобы.
- Статистика ниже очередей, без раскрытия данных разделов, на которые нет прав.

## 4. Таблицы и проверка заявок

- Поиск отзывов с понятной подсказкой, быстрые фильтры статуса и сброс.
- Полный текст отзыва доступен в таблице; диагностические флаги с понятными названиями.
- Оценка риска с объяснением шкалы; отсутствие проверки отличается от отсутствия флагов.
- Сравнение текущих и предложенных значений в заявках на изменение приложения/дистрибуции.
- Сохранение фильтров при переходах; понятные действия и причина отклонения.

## 5. Проверка

- Регрессии: активное меню, права рабочего стола, переключение языка, фильтры и экранирование текста.
- Django system checks и стиль изменённых Python-файлов.
- Визуальная проверка обеих тем и узкого экрана на доступном экземпляре админки.
- Не переносить современные компоненты админки в публичный IE6-интерфейс.

## Следующие итерации

После проверки ежедневной работы команды: переход к следующей заявке, расширенное сравнение медиа,
общие подтверждения массовых решений, аудит оставшихся старых экранов Constance/noSpam/рассылки.
Эти изменения требуют отдельной проверки сценариев и не должны менять семантику удаления отзывов.

## Выполнено в первой итерации

- Исправлена подсветка меню; разделы сгруппированы по задачам, добавлены поиск и счётчики очередей.
- Избавились от верхних вкладок, дублировавших боковое меню и фильтры отзывов.
- Включены пять языков; переведены новые компоненты, подписи отзывов, поиск меню и выбор темы.
- Новые строки используют именованные ключи `PAGE_ADMIN_PANEL_*`; тексты находятся в `msgstr` всех пяти локалей.
- Главная показывает все восемь очередей, старейшую запись каждой очереди и разрешённую статистику.
- Таблица отзывов стала компактнее; статусы и риск читаются в обеих темах, флаги имеют понятные подписи.
- Добавлены фильтры статуса, сброс поиска, сортировка по оценке и риску; полный отзыв открывается из текста.
- Заявки на изменение приложения и дистрибуции показывают сравнение применяемых значений, включая переводы.
- Общее окно отклонения локализовано, поддерживает Tab/Shift+Tab, Escape и возврат фокуса.
- Убрана анимация логотипа, добавлены reduced-motion и адаптивные размеры полей Constance.
- Проверены 28 тестов, Django system checks, pycodestyle, Babel и сборка каталогов переводов.
- Визуально проверены обе темы отзывов, рабочий стол на 390 px и диалог отклонения на локальном предпросмотре.
- Выровнена шапка боковой панели; выбор темы помещается в меню на всех языках, низкие экраны поддерживают прокрутку.

Оставшаяся работа: перевод всех старых полей и сообщений, унификация отдельных экранов noSpam/рассылки/Constance,
расширенное сравнение медиа и проверка сценария «следующая заявка» с командой модерации.
Предпросмотр использовал демонстрационные отзывы; реальные решения модерации при проверке не выполнялись.
