**LunaStore** — это проект энтузиастов, созданный для любителей ретро-эстетики. Он позволяет легко находить и скачивать программы под старые операционные системы, в первую очередь для Windows XP.

**LunaStore** построен на довольно свежем стэке, чтобы гарантировать быструю работу, хорошую оптимизацию и работу даже в Internet Explorer 6:

* **Язык и движок:** Django (Python), собственный движок LunaSpire (написан на Go; для CDN и прочих других крутых вещей в будущем)
* **База данных:** PostgreSQL 18
* **Инфраструктура:** Docker, Docker Compose
* **Аутентификация:** имеется поддержка OpenID (OIDC)
